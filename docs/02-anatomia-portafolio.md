# 02 · Anatomía de un portafolio de arquitectura

## Secciones (en orden por defecto)

| # | Sección | Propósito | Extensión orientativa (PDF estándar) |
|---|---------|-----------|--------------------------------------|
| S1 | **Portada** | Nombre, disciplina, una imagen representativa | 1 página |
| S2 | **Perfil** | Quién soy en ≤ 50 palabras + datos clave | ½–1 página (puede ir junto al índice) |
| S3 | **Índice** | Mapa visual de los proyectos | ½–1 página |
| S4 | **Proyectos** | El núcleo del portafolio | 70–80 % del total |
| S5 | **Otros trabajos** | Concursos, dibujo, fotografía, investigación, en formato compacto | 1–3 páginas |
| S6 | **CV / trayectoria** | Formación, experiencia, software, idiomas | 1 página |
| S7 | **Cierre / contacto** | Última impresión y siguiente paso | 1 página |

## Estructura interna de un proyecto (S4)

Todos los proyectos siguen la misma secuencia (ver ley de similitud, `SIM-R3`):

| Bloque | Contenido | Nivel de detalle (ver divulgación progresiva) |
|--------|-----------|-----------------------------------------------|
| P1 · Apertura | Imagen protagonista + nombre + frase síntesis + ficha técnica | N1 |
| P2 · Concepto | Idea en ≤ 150 palabras + 1–3 diagramas | N2 |
| P3 · Planimetría | Emplazamiento, plantas, cortes, elevaciones | N2 |
| P4 · Imágenes | Renders o fotografías de obra | N2 |
| P5 · Proceso / detalle | Croquis, maquetas, detalles constructivos | N3 |

## Ficha técnica

Campos en un orden fijo; los campos vacíos **se ocultan** (nunca se muestra "N/A"):

1. Nombre del proyecto
2. Año
3. Ubicación
4. Programa / tipología
5. Superficie (m²)
6. **Estado:** académico · concurso · en desarrollo · construido
7. **Rol del autor** (obligatorio)
8. Equipo / oficina / profesor guía (créditos)
9. Herramientas (software)

## Tipos de contenido y su tratamiento

| Tipo | Rasgos | Tratamiento requerido |
|------|--------|-----------------------|
| **Render** | Imagen generada | Se etiqueta como render cuando el proyecto no está construido |
| **Fotografía de obra** | Imagen real | Crédito del fotógrafo cuando corresponda |
| **Plano técnico** | Línea, escala | Título + escala gráfica + norte como un solo grupo; debe ser legible al tamaño de la página |
| **Diagrama** | Abstracción conceptual | Estilo gráfico propio, distinto del plano técnico |
| **Croquis** | Dibujo a mano | Fondo neutro; se agrupa con el proceso |
| **Maqueta** | Foto de objeto físico | Se agrupa con el proceso; fondo neutro |
| **Lámina completa** | Pieza de entrega original | Solo como anexo o en N3; nunca como página principal |
| **Texto** | Concepto, perfil | Respetar el límite de palabras de cada bloque |

## Formatos de salida candidatos

| Formato | Uso típico | Observación |
|---------|-----------|-------------|
| PDF A3 horizontal | Postulación a oficina | Estándar en la disciplina; se lee en pantalla e imprime bien |
| PDF A4 horizontal / vertical | Convocatorias académicas | Muchas veces lo exige la convocatoria |
| PDF 16:9 | Lectura solo en pantalla | Aprovecha mejor monitores y laptops |
| **Muestra** (3–5 págs.) | Primer contacto / email | Derivada automáticamente del portafolio completo |
| Web responsive | Clientes, presencia permanente | Requiere decisiones propias (navegación, carga) |

> **Decidido (D1, D2):** v1 es una **revista interactiva** compuesta en spreads √2:1 (= A3 horizontal), dividida en páginas A4 verticales en móvil y exportable a PDF. Ver [08-revista-interactiva.md](08-revista-interactiva.md).
