# 02 · Carga cognitiva — `CC`

**Principio:** la atención es limitada; todo lo que no ayuda a entender compite con lo que sí ayuda.

**Traducción a arquitectura:** el hábito de taller es **llenar la lámina**, porque en una entrega todo debe estar. Un portafolio funciona al revés: cada página tiene **una idea** y una **imagen protagonista**. El lector no tiene contexto del proyecto, así que no puede descifrar una lámina densa.

**Aplica a:** lector.

## Reglas

| ID | Regla |
|----|-------|
| CC-R1 | **Una imagen protagonista por página** (≥ 50 % del área útil) y como máximo 3 imágenes secundarias. |
| CC-R2 | **Límites de texto:** frase síntesis ≤ 20 palabras; concepto ≤ 150 palabras; perfil ≤ 50 palabras; pie de imagen ≤ 15 palabras. |
| CC-R3 | La plantilla usa una **paleta neutra** (blanco, negro, grises y como mucho 1 acento) para no competir con las imágenes. |
| CC-R4 | **Proyectos completos: 4–6.** El resto pasa a "Otros trabajos" en formato compacto. |
| CC-R5 | Las láminas de entrega completas nunca son página principal (ver `TES-R7`). |
| CC-R6 | **Legibilidad de planos:** si al escalar un plano al tamaño de página sus textos quedan por debajo del mínimo legible, el sistema advierte y propone mostrar una **ampliación parcial** + la planta completa en pequeño como referencia. |
| CC-R7 | Sin ornamentos: marcos, sombras y texturas de fondo solo si comunican algo. |

## Verificación

| ID | Comprobación |
|----|--------------|
| CC-V1 | Cada página tiene exactamente 1 imagen protagonista. |
| CC-V2 | Ningún bloque supera su límite de palabras. |
| CC-V3 | La cantidad de proyectos completos está entre 4 y 6 (configurable). |
| CC-V4 | No hay advertencias de legibilidad de planos sin resolver. |

## Antipatrones

- Un collage de 12 renders en una página.
- Una lámina A0 reducida a A3 con rótulos de recintos ilegibles.
- Textos de memoria explicativa de 600 palabras.
- Fondos con texturas de hormigón o madera "para dar ambiente".

## Relaciones y conflictos

- **Pareto:** define qué proyectos sobreviven al límite de CC-R4.
- **Divulgación progresiva:** lo que CC saca de la página principal no se pierde; baja de nivel.
- **Conflicto con el reclutador (L1):** quiere ver planimetría técnica. Se resuelve con CC-R6 y DP: el plano se muestra, pero legible.

## Preguntas abiertas

- ¿Cómo se mide la "legibilidad" de un plano raster? Una opción es pedir al autor la escala original y calcular el tamaño de texto resultante; otra es usar OCR. Se decide en la Fase 2.
- ¿El límite de 4–6 proyectos cambia según el perfil? (A1 podría tener 3–4, A3 podría tener 6–8).
