# 05 · Principio de Pareto — `PAR`

**Principio:** una minoría de causas produce la mayoría de los efectos (≈ 80/20). Es una observación empírica, no una proporción exacta.

**Traducción a arquitectura:** dos o tres proyectos convencen al lector; el resto acompaña. Dentro de cada proyecto, dos o tres piezas (la imagen, la planta, el corte) cuentan casi todo. Y un puñado de datos (rol, software, estado) responde la mayoría de las preguntas de un reclutador.

**Aplica a:** ambos (el lector recibe la jerarquía; al autor se le pide curar).

## Reglas

| ID | Regla |
|----|-------|
| PAR-R1 | **Curaduría obligatoria:** el autor marca sus **proyectos principales** (entre 2 y 3). Estos reciben **≈ 70 %** de las páginas de proyectos. |
| PAR-R2 | Por proyecto, el autor (o el sistema, por tipo de pieza) identifica **2–3 piezas clave**, que reciben el mayor tamaño. |
| PAR-R3 | **Datos de alto valor siempre visibles** en la ficha: rol, estado y software. No se pueden ocultar. |
| PAR-R4 | **Muestra corta derivable:** a partir del portafolio completo, el sistema genera una versión de 3–5 páginas con portada, el pico, las piezas clave de los proyectos principales y el cierre. |
| PAR-R5 | La **relevancia** de un proyecto depende del lector objetivo: si la descripción menciona la oficina o el área (vivienda, patrimonio, paisaje), los proyectos afines suben de prioridad. |

## Verificación

| ID | Comprobación |
|----|--------------|
| PAR-V1 | Páginas de proyectos principales / páginas de proyectos ≥ 0,6. |
| PAR-V2 | Las piezas clave de cada proyecto tienen mayor área que el resto de sus piezas. |
| PAR-V3 | Toda ficha muestra rol, estado y software. |

## Antipatrones

- Seis proyectos con exactamente cuatro páginas cada uno.
- Un proyecto de primer año con el mismo despliegue que el proyecto de título.
- Una ficha que lista la superficie y el año, pero no el rol.

## Relaciones y conflictos

- **Carga cognitiva:** Pareto decide **qué** se queda y CC decide **cuánto** cabe.
- **Divulgación progresiva:** lo que no está en el 20 % baja a N3 o a "Otros trabajos".
- **Posición serial y pico y final:** usan la jerarquía de Pareto para ordenar.

## Preguntas abiertas

- Si el autor no marca proyectos principales, ¿se bloquea la generación o se usa un criterio por defecto (por ejemplo, el más reciente o el construido)? Propuesta: preguntar siempre (`TES-R6`).
